# Go10 Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the personal site with Go10, a light, lightweight static blog (go10.dev) built from Markdown files and deployed by Netlify.

**Architecture:** A dependency-light Node (ESM) build script reads `content/posts/*` and `content/about.md`, renders them with plain template functions into `dist/`, and copies `static/` (CSS, font, character images) alongside. Pure functions live in `lib/` and are unit-tested with `node:test`; `build.js` only wires them together.

**Tech Stack:** Node ESM, `marked` (only runtime dependency), `node:test`, Netlify (`netlify.toml`).

**Spec:** `docs/superpowers/specs/2026-10-12-go10-blog-design.md`

## Global Constraints

- Site name `Go10`, tagline `Engineering Animation`, domain `https://go10.dev`, `lang="en"`.
- Light mode only: `<meta name="color-scheme" content="light">` and `color-scheme: light` in CSS. Text `#111`, secondary `#333` / `#666`, background white. Font Walter Turncoat, self-hosted (latin woff2, `font-display: swap`). No requests to third-party hosts at runtime.
- Static output only, no framework, no bundler. Only runtime dependency: `marked`. Cross-platform Node (Windows dev machine); never shell-specific scripts.
- Post file: `content/posts/<slug>.md` or `content/posts/<slug>/index.md`, front matter `title`, `date` (YYYY-MM-DD), `summary`, optional `draft: true` (excluded). URL `/<slug>/`.
- Home page: title, tagline, nav `Posts` / `About` / `RSS`, posts newest first as date + title link + one-line summary, a 64x64 character picture (`object-fit: contain`, `alt=""`) left of each row. No tags, no intro paragraph.
- Characters: the owner's drawings numbered 1, 8, 9, 26, 44, 45, 46, 47, 54, 56, 57, 60, 61, 62, 63, shrunk to 128px long edge, in `static/characters/`. Rows on the home page get different characters (repeat only when posts outnumber characters). Post page ends with one random character as sign-off. A deterministic build-time default is written in the HTML; a tiny inline script re-rolls it on load.
- Typical post page without images: well under 100 KB total including font and character.
- Responsive: single column, 16px side gutters, text column max about 40em. Visible focus styles, AA contrast.
- About links: `https://github.com/mateojacques`, `https://linkedin.com/in/mateoleonjacques`, `mailto:mateojacquesweb@gmail.com`.
- Netlify: `netlify.toml` build command `npm run build`, publish `dist`, pinned `NODE_VERSION`.

## Review Focus

- Zero published posts: home page renders a friendly empty message and the feed is still valid.
- `&`, `<`, `>`, `"` in a title or summary are escaped in HTML text, attributes, `<title>` and in the RSS XML.
- Two posts with the same date have a stable order (by slug) so builds are deterministic.
- Non-ASCII titles (for example accents) render correctly, and slugs come only from file or folder names, so they are never derived from titles.
- A post folder with images beside `index.md` works: images are copied to the output, and Windows path separators never leak into URLs.

### Task 3: Character images and selection logic

**Files:**
- Create: `scripts/make-characters.js`, `static/characters/c1.png` .. `c15.png`, `lib/characters.js`, `test/characters.test.js`

**Interfaces:**
- Produces in `lib/characters.js`:
  - `CHARACTERS: string[]`, exactly 15 file names `c1.png` .. `c15.png`, in the order of the owner's numbers listed in Global Constraints.
  - `assignDefaults(slugs: string[]): Record<string, string>`, deterministic: starts from a hash of each slug, and moves to the next unused character on collision, so while `slugs.length <= 15` all values are distinct.
  - `distinctRandom(count: number, pool: string[], rng: () => number): string[]`, a shuffled selection with no repeats until `count > pool.length`, then the shuffle restarts. Must be written as a self-contained function with no outside references, because the build inlines it in the page with `Function.prototype.toString()`.
